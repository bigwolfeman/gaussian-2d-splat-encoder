# Provenance and limits

- Encoder and renderer source came from `bigwolfeman/gaussian-jepa` commit `e15e9436d5bd891a809b451f3762ba22eca6fac1`. The copied modules are `gaussian_jepa/encoder/{efficient_encoder,render_triton,render,params}.py`. The four source files are byte-identical; only their package directory name changed.
- The checkpoint is the frozen `encoder_golden_d256.pt` at training step 6000. It has 833,107 parameters and SHA-256 `ff7ebf0167173bb17c9d84317cf8eb33e2fdd050bca90dcac366b9e98992da2f`. It was trained from scratch on 2,936 source/golden-render pairs. No training source images are included here.
- The checkpoint's saved config has `init_ckpt: null` and no DINO auxiliary loss. Training did use [`torchvision.models.VGG19_Weights.DEFAULT`](https://github.com/pytorch/vision/blob/main/torchvision/models/vgg.py) as a frozen perceptual-loss network. Those teacher weights are not in this release. [TorchVision states](https://github.com/pytorch/vision#pre-trained-model-license) that pretrained weights can have separate terms derived from their training data. This review did not establish the checkpoint's redistribution or downstream license status. The Apache-2.0 grant covers only this author's source code. It does not grant rights to ImageNet, TorchVision weights, or source training images.
- The archived 64-image held-out result in the README came from the original `encoders-v1` release in the private project. The source validation images are not included, so this release does not independently reproduce that result.
- `examples/make_samples.py` drew every target in `samples/targets/` with Pillow and DejaVu Sans. The encoder and renderer made `samples/reconstructions/` from those targets. No MOVi, ReLaion, or other third-party image is included. The test cards and their generated output are CC BY 4.0, with attribution to Wolfe (bigwolfeman).
- The three public panels were rendered on an NVIDIA GeForce RTX 3070, driver 590.48.01, PyTorch 2.12.0+cu130, Triton 3.7.0, NumPy 2.4.6, and Pillow 12.2.0. `examples/encode_and_render.py --benchmark` used 5 warmups and 30 CUDA-event timings for each 768 × 768 image. PSNR is against the original target, with pixel values scaled to [0,1]. The same script produced `samples/reconstructions/measurements.json`.
